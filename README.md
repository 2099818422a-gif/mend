mend is a single-file patch CLI (main.ts, Node 22, standard library only) that applies AI-written edits to a tree of text files in four formats: unified diffs (even with wrong line numbers), SEARCH/REPLACE blocks, V4A patches, and JSON tool-call edits — with safe-path checks and all-or-nothing writes, so a failed edit changes nothing.

## Run it

```sh
node main.ts patch.diff
```
